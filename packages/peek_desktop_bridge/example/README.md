# Peek Bridge 示例

使用测试数据演示配对、网络请求、Talker 日志和异常同步。目前包含 macOS 工程，手机接入方式见[连接包](../../peek_desktop_connect/README.md)。

## 启动

先在 Peek Desktop 的“设备连接”中启动监听并生成配对码，再从本目录运行：

```bash
flutter pub get
flutter run -d macos --dart-define=PEEK_DESKTOP_DIAGNOSTICS=true
```

示例只在 Debug 且上述开关为 true 时初始化诊断。Release/Profile 不初始化连接和日志订阅。

## 连接电脑

同机可输入 `127.0.0.1:9741` 和四位配对码，也可直接粘贴桌面生成的配对链接。要使用自动发现，在桌面选择“局域网设备”并开启 mDNS，再点击示例的“搜索局域网电脑”。

配对成功后，网络状态为 `connected`，日志状态为 `ready`。连接过的电脑出现在历史列表，之后可免码切换；每次只连接一台。电脑 IP 变化时，可从发现列表选择同一电脑的新地址。

macOS 示例通过粘贴链接演示配对，不包含相机插件。手机 App 将自己的扫码页面接入 `DesktopConnectionPanel.onScan`；手机填写电脑的局域网 IP。

## 测试按钮

| 按钮 | 产生的数据 / 查看结果 |
| --- | --- |
| 生成测试请求 | 一条 GET 请求及明确引用它的日志，可从时间线跳转请求 |
| 异常查看示例 | 三条相同指纹异常、一条空堆栈异常、一条属性截断事件；用于检查分组和详情 |
| 连续发送 120 条日志 | 108 条 info、12 条 warning，间隔 25 ms；用于检查跟随、暂停和筛选 |
| INFO 日志 / WARN 日志 | 一条对应级别的 Talker 记录 |
| 异常与堆栈 | 一条携带 Dart 原始堆栈的异常 |
| 脱敏示例 | 含测试 token 的属性，桌面应显示脱敏后的值 |
| 清空待发日志 | 重置发送上下文，不删除电脑配对 |
| 重试日志连接 | 桌面重新允许诊断后，手动重试连接 |

发送完成并收到确认后，待发数应回到 0。桌面“暂停跟随”只停止自动滚动，仍继续接收日志。

按钮使用合成请求和日志，不访问业务 API。切换电脑会清空旧目标的待发诊断；网络历史则由官方 PeekRemote 从当前 Peek store 同步。
