# Peek Bridge Demo

在 Peek Desktop 启动监听并生成配对码，然后运行：

```bash
flutter pub get
flutter run -d macos --dart-define=PEEK_DESKTOP_DIAGNOSTICS=true
```

同机可填 `127.0.0.1:9741`；手机连接应填写电脑实际局域网 IP。局域网自动发现需桌面选择“局域网设备”并开启 mDNS，再点击示例“发现局域网桌面”。示例使用独立 `peek_desktop_connect`：首次填写四位码或粘贴桌面的配对链接，成功后可从“历史桌面”直接免码切换；发现同一桌面的新 IP 也能直接连接。每次只连接所选一台电脑，单独“忘记”不影响其他配对。手动修改地址会清除发现结果的身份选择，未知地址首次需配对码。

macOS 示例演示链接粘贴，不安装相机扫码插件。手机宿主将现有扫码页传给 `DesktopConnectionPanel.onScan`，点击“扫码绑定”即可解析二维码并发起配对，具体见 [连接包 README](../../peek_desktop_connect/README.md)。示例界面跟随系统中英文，原有合成数据按钮保留中文。

示例只在 debug 且显式开关打开时构造 memory、remote、bridge；Release/Profile 不初始化诊断。按钮产生合成网络、普通日志、警告与原始异常堆栈，不访问业务 API。网络使用原版 PeekRemote，日志复用其公开配对信息。切换桌面时诊断旧目标待发队列会清空，官方网络客户端则按原协议向新桌面发送本地 Peek store 的请求历史。

P2 查看验收可使用以下按钮：

- “生成合成请求”同时发送明确引用该请求 ID 的日志，用于时间线及详情跳转。
- “P2 分组 / 空堆栈 / 截断”发送三条同指纹异常、一条空堆栈异常，以及属性超过 SDK 限制且引用不存在请求的事件，用于验证分组成员、截断说明和不可用关联。
- “连续 120 条日志”以 25 ms 间隔发送带来源、奇偶 tag 的合成日志，其中 108 条 `info`、12 条 `warning`，用于筛选、多选导出及跟随/暂停。停止跟随只暂停桌面滚动，客户端继续发送。级别必须使用协议的 `warning`，`warn` 会被 SDK 拒绝。
